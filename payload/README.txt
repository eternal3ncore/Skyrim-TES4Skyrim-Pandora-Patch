The build expects these two TES4Skyrim/TES4Converter-generated files in this directory:

  animationdatasinglefile.txt
  animationsetdatasinglefile.txt

The v0.3 test package used the converter snapshot validated as:
  animationdatasinglefile.txt: 539 projects, 110 TES4 projects, all 110 with MotionData
  animationsetdatasinglefile.txt: 159 projects, 110 TES4 projects

They are converter data payloads rather than patch source code and are not included in this source repository upload. Place the matching converter files here before running build.ps1.
